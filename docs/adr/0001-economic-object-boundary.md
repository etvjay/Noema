# ADR 0001: Economic object boundary

## Context

Token contracts and economic claims are related but not identical.

## Decision

Noema's canonical object is an Evidence-Bounded Economic Object. A token or
other representation is one relation-bearing input to that object.

## Consequences

Identity, rights, restrictions, evidence, and representation relationships can
be evaluated without collapsing them into a token registry.

## Reopen condition

Reopen only if a demonstrated source or evaluator requirement proves the
object boundary cannot represent an MVP asset case.
