# ADR 0005: AI is proposal-only

## Context

Source documents and model output are semantically useful but unsafe as direct
authority.

## Decision

AI may propose claims, relationships, rights, restrictions, conflicts, and
unresolved issues. Deterministic reducers and verifiers alone may establish
verified state.

## Consequences

The system can expose AI value without allowing prompt content or model
confidence to authorize capital-affecting actions.

## Reopen condition

Never reopen the proposal-only boundary; improve evidence and verification
instead.
