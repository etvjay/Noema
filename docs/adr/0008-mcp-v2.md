# ADR 0008: MCP boundary

## Context

Agents need read-heavy access to resolved economic intelligence.

## Decision

Expose MCP over Streamable HTTP after the base REST/domain contracts pass
conformance tests. MCP tools read Noema state and create bounded watches; they
do not execute finance.

## Consequences

The agent surface remains composable and auditable.

## Reopen condition

Reopen transport details after current official MCP SDK tests are run.
